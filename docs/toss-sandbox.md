# 토스 SDK v2 주문서형 샌드박스

`pueblo/public/toss-sandbox.json`의 clientKey에 위젯용 `test_gck_` 클라이언트 키를 설정합니다. 이 파일은 공개 설정입니다. 시크릿 키를 넣으면 안 됩니다. 배포 시 이 정적 파일을 교체해도 되며 Docker 빌드 ARG는 필요하지 않습니다.

장바구니에서 상품을 선택하고 동의 후 결제하기 → /checkout에서 결제수단·약관 위젯 → 테스트 결제 → 인증 결과 화면 순서입니다. 모바일도 지원하는 successUrl/failUrl 리다이렉트를 사용합니다. SDK 및 위젯 UI 준비 전에는 결제 버튼이 비활성화됩니다.

현재 백엔드 API 계약과 위젯 테스트 키가 제공되지 않아 실제 승인은 연결하지 않았습니다. 성공 URL은 인증 결과일 뿐 결제 완료가 아니며 장바구니를 비우거나 주문을 완료 처리하지 않습니다. 세션의 금액 비교는 UX 검증이며 신뢰할 수 있는 결제 검증이 아닙니다.

백엔드 연동 시 서버가 가격·배송비·할인을 계산하고 주문번호와 금액을 저장해야 합니다. 인증 결과의 paymentKey, orderId, amount를 승인 API에 전달하고, 서버가 주문 소유자·금액·중복 승인을 검증한 뒤 비밀 키로 토스 승인 API를 호출해야 합니다. 백엔드의 최종 승인 응답을 받은 후에만 완료 표시와 장바구니 정리를 수행합니다.

참고: https://docs.tosspayments.com/sdk/v2/js/payment-widget
